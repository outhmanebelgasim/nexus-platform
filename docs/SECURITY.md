# Security

## Authentication Flow

```text
Client submits email/password
    -> AuthController.login
    -> AuthService
    -> AuthenticationManager
    -> CurrentUserDetailsService
    -> BCrypt password check
    -> JwtService generates JWT
    -> Client stores token
    -> Axios sends Bearer token on protected requests
```

## JWT

JWTs are generated by `JwtService` and validated by Spring Security OAuth2 Resource Server support.

Claims:

- `iss`: configured issuer.
- `sub`: user email.
- `userId`: database user id.
- `role`: role enum name.
- expiration timestamp.

Algorithm: HS256.

## Password Encoding

`SecurityConfig` uses `BCryptPasswordEncoder`.

Password update requests require:

- current password;
- new password;
- confirmation password;
- new password length between 8 and 128 characters.

## Authorization

Global URL authorization:

| Area | Roles |
| --- | --- |
| Login/register | Public |
| Current auth/profile endpoints | Authenticated |
| User administration | `SUPER_ADMIN`, `ADMIN` |
| Farm/station reads | All authenticated roles |
| Farm/station writes | `SUPER_ADMIN`, `ADMIN` |
| Measurement-variable, measurement, alert, import-log reads | All authenticated roles |
| Measurement-variable, measurement, alert, import-log writes | `SUPER_ADMIN`, `ADMIN` |
| Importer monitoring | `SUPER_ADMIN`, `ADMIN` |

Service-level authorization applies data scoping through `AccessControlService`.

## Roles

Confirmed role names:

- `SUPER_ADMIN`
- `ADMIN`
- `TECHNICIAN`
- `VIEWER`

## Data Access Scope

Access-scope tables:

- `user_farm_access`
- `user_station_access`
- `user_measurement_variable_access`
- `user_measurement_type_access`

These support restricting operational users to specific farms, stations, variables, and measurement semantic types.

## CSRF and Sessions

CSRF is disabled and sessions are stateless. This matches bearer-token API usage.

## Security Notes From Code

- The default JWT secret in `application.properties` is development-only and must be replaced outside local development.
- The database migrations include development seed accounts and comments marking them as development-only.
- Importer monitoring intentionally exposes safe display paths rather than sensitive absolute source paths in the current project memory and API design.
