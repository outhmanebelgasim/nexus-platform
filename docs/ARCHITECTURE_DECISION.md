# NEXUS Platform — Architecture Decisions

This document records important decisions that future developers and coding agents must preserve unless an explicit architecture change is approved.

---

## ADR-001 — Existing acquisition applications remain unchanged

### Decision

NEXUS does not communicate directly with weather stations or sensors.

It consumes processed `.dat` files generated by existing Java applications on a Windows Server.

### Reason

The existing acquisition and cleaning process is already operational and is outside the NEXUS project scope.
